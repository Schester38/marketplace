Intégration H2H (Payin, Payout & Webhooks)
Endpoint Live :
https://api.ikeepay.com
Header d'authentification :
x-api-key: SECRET_KEY
1. Encaissement (Payin)
POST /h2h-payin
Payload de la requête
{
  "amount": 500,
  "currency": "XOF",
  "country": "CI",
  "phoneNumber": "2250700000000",
  "operator": "ORANGE", // OU MTN, WAVE, MOOV, MOBICASH, AIRTEL, VODACOM...
  "external_reference": "REF_1700000000",
  "customer_email": "client@example.com",
  "otp": "123456" // si requis EX: ORANGE BF 
  //  Vous recevrez un lien de redirection payment_link en reponse pour le cas de wave et orange si neccesaire
}
2. Retrait (Payout)
POST /h2h-payout
Payload de la requête
{
  "amount": 200,
  "currency": "XOF",
  "country": "CI",
  "phoneNumber": "2250700000000",
  "operator": "ORANGE",
  "external_reference": "PAYOUT_1700000000"
}
3. Webhooks (Notifications Async)
POST
Notre serveur envoie automatiquement un payload JSON à votre URL de notification dès qu'une transaction est créée ou mise à jour.

Structure du JSON reçu
{
  "event": "transaction.updated", // ou "transaction.created"
  "data": {
    "type": "payin", // ou payout
    "external_reference": "REF_1700000000",
    "provider_reference": "IKP-H2H-B5C9EC0E",
    "amount": 500,
    "currency": "XOF",
    "country": "CI",
    "phone_number": "2250700000000",
    "operator": "ORANGE",
    "status": "completed", // ou pending, failed
    "site": "Production",
    "created_at": "2026-08-08T18:00:00Z",
    "updated_at": "2026-08-08T18:00:05Z"
  }
}
